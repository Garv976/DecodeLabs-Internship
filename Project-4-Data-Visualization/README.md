# Data Visualization

## Objective

The objective of this project is to create meaningful visualizations that communicate insights from the dataset using Python.

## Project Overview

This project focuses on exploring the dataset through different types of charts to identify trends, comparisons, distributions, and relationships between variables.

## Visualizations Used

- Bar Chart
- Line Chart
- Pie Chart
- Histogram
- Scatter Plot
- Box Plot 

## Tools & Libraries

- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

## Files Included

- `Data_Visualization.ipynb` – Jupyter Notebook containing the complete visualization process.
- `README.md` – Project documentation.

## Outcome

Created clear and informative visualizations that help understand the dataset and communicate key insights effectively.
